ShiftBrief 0.1.0 - Windows x64

Open ShiftBrief from the Start menu or your optional Desktop shortcut.
The included Python runtime starts a local server and opens your browser.
A fresh installation starts with a blank business. Choose Create a business,
Load saved business, Restore backup from previous computer, or Load demo.
Maple Street demo records are invented and load only when you choose them.

Records - offline needs no account, API key, model download, or subscription.
Optional AI - local Ollama needs your separately installed Ollama and an
appropriate local model; model weights are not included in this installer.

Your business records are stored in:
  %LOCALAPPDATA%\ShiftBrief\data
They are separate from the installed program and remain after uninstall.
Use Save business copy or Back up all businesses to keep portable backups.
Source files you linked from elsewhere need their own backup and relinking.

Closing the browser does not stop the local server. To close the application,
use Start > ShiftBrief > Close ShiftBrief. Close it before upgrading or
uninstalling. Uninstall through Windows Settings > Apps or the Start-menu
Uninstall ShiftBrief shortcut. Your saved business folder is preserved.
